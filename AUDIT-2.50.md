# Проверка совместимости 2.50 · 1 ноября 2026

Исправлены два риска интеграции и добавлена очистка графических ресурсов. Это проверка выбранных сценариев, а не гарантия отсутствия любых ошибок.

## Исправления

- Игровые сообщения теперь помечают chatMetadata.tainted и вызывают стандартные события SillyTavern до и после отрисовки: MESSAGE_SENT / USER_MESSAGE_RENDERED для пользователя и рассказчика; MESSAGE_RECEIVED / CHARACTER_MESSAGE_RENDERED с типом command для бота. Другие расширения могут обработать их как обычные добавленные сообщения.
- После асинхронных событий и сохранения повторно проверяются текущий чат, его массив сообщений и ревизия. Смена чата не превращает незавершённую отправку в ложный успех. Повторное сохранение не дублирует сообщение, отрисовку или события. Если нативный рендерер частично вставил сообщение и выбросил ошибку, повторная отправка не вставляет вторую копию DOM; для восстановления отображения может потребоваться переоткрыть чат.
- При отключении освобождается WebGL-контекст дурака; при ошибке создания шейдера он также освобождается. Это профилактика накопления графических ресурсов, а не утверждение о воспроизведённом падении Таверны.

## Ограничения

Не проверялись установленная у пользователя версия, её сторонние плагины, Safari/iOS и реальные платные API генерации. Мобильная эмуляция Chromium не равна проверке на физическом телефоне. Полные партии во всех играх не проходились браузерным сценарием.

Публичный ctx.saveChat в проверенной версии SillyTavern вызывает saveChatConditional, который перехватывает часть ошибок сервера без возвращения признака неудачи. Расширение обрабатывает отклонённые promises, но не может гарантировать запись на диск, если сам хост скрыл ошибку. Прямые обходы нативного сохранения не добавлялись. Успешная запись в локальном тестовом сервере проверена отдельно.

Нативные события позволяют другим плагинам запускать настроенные ими обработчики; их поведение зависит от конфигурации пользователя.
