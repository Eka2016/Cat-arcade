# 3.0.5

- Основа: приложенная Paw-Arcade-v3.0.3.zip; её четыре арта и логика эмоций дурака сохранены без изменений.
- Порядок меню: Домино → Английский → ДНД.
- Настройки → Персонажи → Дурак: одежда: Синяя кофта / Рубашка. Старые настройки сохраняют синюю кофту.
- Рубашка из IMG_85217.PNG подогнана к исходной позе отдельным артом. Один дополнительный статичный слой одежды, поверх которого остаются исходная голова и мимика 3.0.3.
- Рубашка загружается только при показе персонажа с выбранной одеждой. Скрытая игра не запускает её загрузку или декодирование.
- При ошибке загрузки остаётся кофта; ошибка сохранения возвращает прежний выбор.

Проверка: 368 автоматических тестов прошли; статичные композиции рубашки проверены для всех четырёх эмоций. На физическом iPhone не проверено.
