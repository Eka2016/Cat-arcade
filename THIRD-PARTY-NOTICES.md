# Сторонний код

Для проверки шахматных правил включена **chess.js 1.4.0**, автор Jeff Hlywa и участники проекта: https://github.com/jhlywa/chess.js.

Файл `vendor/chess.js` — ESM-сборка из npm-пакета chess.js 1.4.0. Удалена только ссылка на отладочную source map. Полная лицензия BSD-2-Clause сохранена в `vendor/chess-LICENSE.txt`, включая авторское уведомление и условия распространения. В самостоятельном `demo.html` тот же текст включён в комментарий рядом со встроенным кодом.

Алгоритм шахматного соперника, шашки, домино и карточки слов — код расширения. Пользователю не требуется установка пакетов: библиотека уже включена в архив. При обновлении скопируйте папку `vendor` вместе с остальными файлами.
