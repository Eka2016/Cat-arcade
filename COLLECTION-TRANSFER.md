# Перенос сборников · 2.33

В ДНД, английском и «Правде или действии» открой «Сборники» и нажми маленькую кнопку с двумя стрелками в правой части заголовка. Она доступна и внутри отдельного сборника. Стрелка назад возвращает в прежний список.

## Экспорт

На вкладке «Экспорт» отметь нужные сборники и нажми «Скачать JSON». Из галереи сначала выбраны все сборники; из отдельного сборника — только он. Есть поиск и кнопка выбора всех сборников. Избранное и карточки без сборника доступны отдельными пунктами. Для полной копии всех сохранённых карточек выбери все пункты, включая эти два.

В файл попадают только выбранные сборники и их карточки. Карточка из нескольких выбранных сборников хранится один раз и сохраняет все выбранные связи. Названия других сборников не включаются. Если «Избранное» не выбрано, отметки избранного не экспортируются. Пустые сборники тоже можно сохранить. Незакреплённые в сборниках текущие генерации не входят в эту копию: сначала сохрани их в сборник или избранное.

На телефоне сохрани полученный JSON в файлы устройства. Для переноса на другой компьютер или телефон открой там импорт этого файла. Файл можно передать другому человеку; он получит только выбранные сборники и карточки.

## Импорт

Перейди на вкладку «Импорт», нажми «Выбрать JSON» и открой сохранённый файл. Появятся название игры, количество сборников и карточек. Отметь нужные сборники, затем нажми «Добавить выбранные». Само открытие файла ничего не добавляет. Можно уйти назад или выбрать другой файл.

Импорт добавляет данные к существующим:

- Сборники с одинаковыми названиями объединяются по обычным для этой игры правилам сравнения названий.
- В «Правде или действии» одинаковый текст не создаёт вторую карточку. Если одинаковый текст имеет разные типы («Правда» и «Действие»), весь импорт отменяется с объяснением; нужно изменить текст или тип в исходном наборе.
- В английском совпадением считается пара «слово — перевод». Существующее написание, пример и его перевод сохраняются.
- В ДНД совпадением считается грань кубика, название и текст события.
- Новые связи со сборниками и избранное добавляются; старые связи и отметки не снимаются.
- Старые карточки и сборники не удаляются. Внешние идентификаторы не заменяют местные.
- Повторный импорт того же файла не создаёт новые копии уже существующих карточек или сборников.

После добавления отображаются количества новых сборников, новых карточек и уже сохранённых карточек. Импорт не запускает игру, не меняет текущий набор, выбранный результат, использованные карточки или прогресс. Импортированные слова и события запускаются обычной кнопкой игры внутри соответствующего сборника.

## Хранение и формат

Сборники сохраняются тем же способом, что и остальные карточки расширения: в штатных настройках Paw Arcade внутри SillyTavern. JSON — отдельная копия на устройстве; удаление этого файла не удаляет импортированные карточки, и наоборот.

Перенос работает локально: без запросов к модели, прокси или стороннему сервису. В файл не записываются чат, пресеты, пароли, ключи, настройки подключения, журналы партий или картинки. Проверяется структура файла и обычный текст карточек; содержимое не выполняется как код. Повреждённый файл или ошибка сохранения оставляют прежние сборники без изменений. Файл другой игры нужно импортировать в её разделе.

Один JSON может занимать до 32 МиБ; если данных больше, выбери меньше сборников для каждого файла. Количество карточек в сборнике и длина авторских карточек дополнительными ограничениями переноса не ограничены. Списки сборников отображаются частями для работы с большими коллекциями на телефоне.

Формат первой версии:

```json
{
  "format": "paw-arcade-collections",
  "version": 1,
  "game": "truth",
  "collections": [{"id": "favorites", "name": "Избранное"}],
  "cards": [{"kind": "truth", "text": "Какой вечер тебе запомнился?", "collections": ["favorites"]}]
}
```

`game` принимает `truth`, `words` или `dnd`. У английских карточек используются поля `en`, `ru`, `example`, `translation`; у событий — `roll`, `title`, `event`. Два служебных пункта имеют идентификаторы `favorites` и `ungrouped`; остальные идентификаторы сборников — строки из 32 шестнадцатеричных символов. Карточки содержат только текстовые поля своей игры и массив выбранных связей. Для импорта используют JSON этого формата, а не архив расширения или полный файл настроек SillyTavern.

В 2.33 изменены только перенос сборников, его интерфейс, версия, документация и автономный пример. Изображения, маска лица домино, длительности переходов, общие анимации и игровые движки сохранены из 2.32.
