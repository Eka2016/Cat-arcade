# Paw Arcade 3.0

Основа — приложенный Paw-Arcade-v2.57(1).zip. В эту версию перенесены одобренные пользователем арты дурака и смена мимики по примеру домино.

Неподвижный нейтральный портрет — IMG_8523.PNG. Три эмоции — выбранные арты задумчивости, победы и огорчения. Меняется только область лица; волосы, шея, плечи, кофта, руки и карты остаются из нейтрального изображения. Переходы opacity: 480 мс для задумчивости, 620 мс для возврата, 680 мс для результата; удержание задумчивости и пауза — как в домино. Прежняя маска внешнего силуэта 2.57 заменена маской мимики.

Активные арты: assets/durak-{neutral,thinking,win,lose}-v9.webp. Другие файлы исходного архива сохранены. Параметры подключения к модели, генерации, чат, данные и остальные игры не менялись. Из существующих функциональных файлов изменены только durak-ui.js, durak-portrait.js и стили дурака. Также обновлены тесты портрета и номера версии.

Проверка: все 361 автоматический тест прошли. Сохранность остальных файлов проверена побайтовым сравнением с приложенным архивом. Итоговые композиции эмоций визуально проверены при подготовке переноса. Физический iPhone/Safari не проверялся.
